# 第四本：《彼得潘｜貼紙童話試作》

三頁互動美術原型，用以驗證可愛溫馨、扁平歐風繪本和貼紙遊戲的整體視覺語法。不使用《雷頓教授》或《故事織造家》原有素材／人物設計。

- 3 張原創可愛簡化 SVG 背景、6 個同風格 SVG 貼紙
- 預留明確放置區，座標與整個 4:3 插畫一起縮放
- 3 頁故事文字有內嵌的兩色提示詞；放入任何貼紙即時改文案
- 章節導覽、解謎、返回、獨立 localStorage 存檔
- 與既有 3 本書的圖片、程式和存檔完全獨立

此書為 3 頁美術驗證，不是完整 24 頁重製。確認整體畫風與比例後，再決定是否套用到長篇《彼得潘》。


## 場景角色與貼紙變體（第二版）

本試作採用類似《故事織造家》「情境中的角色作用」設計原則，
不使用該遊戲的美術素材或程式碼。

- 每頁兩個語意放置位置，由 `layout.js` 的 `PETER_SCENE_ROLES` 指定。
  室內：發現者／發現物；天空：飛行者／魔法；森林：幫手／成果。
- `PETER_ROLE_VARIANTS` 讓貼紙依角色位置自動換圖。天空中的彼得、
  溫蒂和迷失男孩使用專門繪製的飛行版本（不是站姿直接縮放）；
  小屋、仙塵和影子使用漂浮版本，森林裡的迷失男孩使用施工姿態。
- `reader.js` 的 `stagePosition()` 完全由 slot 框決定寬與高，
  同一位置不論貼對、貼錯、人物或物品，都以完全一致的視覺框顯示，
  不再依貼紙類型或正解調整尺寸。
- 所有六張貼紙都可放在三頁任一位置；正文同步變更與現有存檔
  `storybook-sticker-demo-v1` 保持相容。

本機 Chrome 回歸測試覆蓋 3 頁 × 2 位置 × 6 張貼紙＝36 種放置狀況，
檢查尺寸一致、變體路徑、畫面邊界及內文更新。
